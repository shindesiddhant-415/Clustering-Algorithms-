## Aim
To implement ensemble learning algorithms on a real-world classification dataset and evaluate their performance using suitable classification metrics.

## Dataset
This project uses the **Breast Cancer Wisconsin (Diagnostic)** dataset available through `scikit-learn`. It contains 569 samples, 30 numerical features, and two target classes. The dataset is loaded automatically by the program; no manual download is required.

## Algorithms implemented
1. Random Forest
2. Bagging Classifier
3. AdaBoost
4. Gradient Boosting
5. Voting Classifier (soft voting)

## Evaluation metrics
- Accuracy
- Precision
- Recall
- F1-score
- ROC-AUC
- Confusion matrix

## Requirements
- Python 3.9 or newer
- scikit-learn
- pandas
- matplotlib

## How to run

```bash
python -m pip install -r requirements.txt
python main.py
```

## Generated output
After successful execution, the `outputs` folder contains:
- `model_comparison.csv` — comparison table for all models
- `classification_report.txt` — detailed classification reports
- `accuracy_comparison.png` — accuracy chart
- `confusion_matrices.png` — confusion matrices for the models

## Notes
The program uses an 80:20 stratified train/test split and `random_state=42` so that the experiment is reproducible. Actual metric values are generated when the program is run in your environment. Do not enter estimated results in the final practical report; use the output generated by your run.
